## 当前风险

1. AppID、测试云环境、集合、索引、云函数和 `hy3` 已配置或部署，但尚未发生可核验的真实云端端到端调用；源码可部署不等于 ASR/AI 已联调。
2. 系统中文 TTS 音频清晰且非静音，但不是专业配音。当前 6 段 M4A 为满足代码包静态资源建议已压缩到 16kHz、单声道、约 12kbps；真实用户若觉得机械或压缩感明显，应把高质量版本迁到云存储/CDN，通过 URL 加载，不在运行时增加 TTS。
3. `wx-server-sdk 4.0.2` 是当前稳定版，但 2026-08-17 的 `npm audit` 仍报告其 CloudBase 传递依赖中的 5 个 high、1 个 moderate，主要是 `axios` 与 `lodash.set/unset`。审计建议降级到 `2.5.3`，实测会增加 critical/high 数量，因此未采用。当前代码只把固定字段和固定集合路径传给 SDK，仍应在发布前跟进官方更新并重新审计。
4. 客户端 45 秒超时不能取消已经在云函数里执行的请求。请求 ID 防止同一提交再次计费；若用户主动“重新分析”，会生成新的请求并消耗新的日额度。
5. 云存储本身没有目录扫描 API，本实现依靠上传后的 `temp_audio_files` 登记做兜底。客户端在登记前断网时会主动删除，但极端进程崩溃仍可能出现未登记孤儿；测试期应定期人工检查 `temp-audio/` 目录。
6. 场景建议是用户主动输入的文本，虽有敏感信息提醒，仍需设定保留期和管理员访问控制。
