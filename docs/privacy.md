# 隐私说明文案

## 小程序内简版

录音只用于本次语音转写和生成三点反馈。处理结束后会立即删除原始录音，异常时也会尝试删除。

我们不长期保存录音或完整转写，不用于模型训练，也不收集姓名、手机号、微信昵称或原始 OpenID。匿名行为数据仅用于限制每日调用次数和了解练习是否有效。

用户填写“还想练什么场景”时，请勿填写个人、同事、客户或公司的敏感信息。

## 首次申请麦克风前

我们需要麦克风录下你的回应，只用于转写和生成本次反馈。处理完成后会删除，不会用于训练模型。

按钮：`继续并授权` / `暂不练习`

## 公众平台隐私指引需要覆盖

- 处理目的：录制会议练习回应、语音转写、生成本次三点反馈。
- 信息类型：麦克风录音、由录音产生的临时转写、匿名行为事件、用户主动提交的场景建议。
- 保存：录音分析结束立即删除；删除失败的临时文件在超过一小时后由定时任务重试。数据库不保存完整转写。
- 第三方：腾讯云语音识别，以及实际选择的 OpenAI 兼容模型供应商。填写真实主体、处理目的、数据种类、服务器地域和供应商政策链接。
- 匿名化：微信 OpenID 只在云函数内用于 HMAC，数据库仅保存不可逆 `userKey`。
- 用户选择：拒绝麦克风不会反复弹窗，可打开系统设置或退出练习。
- 模型训练：正式上线前确认供应商 API 的数据使用设置与合同；如果无法保证不用于训练，不能沿用当前文案。
