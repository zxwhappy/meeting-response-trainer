# 发布前测试清单

## 已自动验证

- [x] 合法状态路径与非法跨状态跳转
- [x] 场景列表只展示启用项、所选场景正确进入练习、所有练习状态可返回场景列表
- [x] 录音不足 3 秒、无录音和重复提交保护
- [x] 三点反馈完整结构与文案长度上限
- [x] 前后变化大于、等于和小于 0 的四类文案
- [x] 每日第 10 次允许、第 11 次拒绝、重复请求不计费
- [x] ASR 少于 5 个有效汉字时不调用 AI
- [x] AI 非法格式自动重试一次、AI 超时可恢复
- [x] 成功、ASR 空结果、AI 超时和前置配置失败均尝试删除音频
- [x] 一小时临时文件清理及部分删除失败隔离
- [x] 腾讯云 TC3 固定签名向量
- [x] 6 个场景 M4A 均为 16kHz、单声道、非小占位文件，代码包内图片和音频合计不超过 200 KB
- [x] JavaScript/JSON 语法、WXML 事件绑定和前端密钥扫描

## 微信开发者工具

- [x] 使用真实 AppID 导入根目录并编译无错误
- [x] 首屏展示 6 个全宽场景卡，点击“项目延期”进入对应的角色和背景
- [x] 听题阶段可直接返回；第一次回应入口返回会二次确认，“继续练习”和“返回选场景”两个分支均正常
- [ ] 准备、实际录音、反馈和分析阶段分别复核返回行为
- [ ] 分析中确认返回后，即使云函数稍后返回也不会跳回反馈页
- [x] “代码质量”重新扫描后显示“未发现代码质量问题”，静态媒体建议项通过
- [ ] 首屏在窄屏、常见 Android 宽度和字体放大下无截断
- [ ] 6 个音频都能播放，第一轮播放前看不到全文
- [ ] 首次隐私同意按钮和麦克风授权流程符合后台指引
- [ ] 拒绝麦克风后可打开设置，也可退出练习
- [ ] 30 秒与 15 秒倒计时按真实时间结束，不会自动开始录音
- [ ] 录音可开始、主动停止、60 秒自动停止、试听、重录和提交
- [ ] 工具模拟“无网络”后出现自然提示，恢复网络可继续
- [ ] 云函数真实返回中文转写和三个结构项
- [ ] 数据库没有完整转写或原始 OpenID
- [ ] 云存储在成功和失败测试后没有遗留录音
- [ ] 手工放入一条超过一小时的测试索引，定时清理能删除文件和索引

## iPhone 真机

- [ ] 听筒/扬声器、静音开关和蓝牙耳机情况下音频符合预期
- [ ] 麦克风首次授权、拒绝、设置页重新开启均可恢复
- [ ] 录音中回到桌面或接到系统音频打断时安全停止，不提交半段录音
- [ ] 刘海屏和底部安全区不遮住主按钮
- [ ] 4G 下首屏目标小于 2 秒，正常分析目标小于 20 秒
- [ ] 45 秒后客户端进入可恢复超时，不白屏或重复扣费
- [ ] 完整两轮后才出现 `practice_complete`

## Android 真机

- [ ] 至少一台主流微信版本完成与 iPhone 相同的全流程
- [ ] 录音 MP3 能被腾讯 ASR 正确识别
- [ ] 系统权限“仅本次允许 / 拒绝 / 设置恢复”均有明确下一步
- [ ] 切后台、锁屏、音频焦点被其他 App 抢占后状态不乱
- [ ] 字体放大和不同状态栏高度不遮挡按钮

## 异常注入

- [ ] 场景音频地址故意改错两次，出现文字降级并写 `audio_fallback_text`
- [ ] 删除一个 ASR 环境变量，生产界面不泄露变量名，开发版能看到技术详情
- [ ] ASR 返回空结果，必须要求重新录音，不能生成三点结论
- [ ] AI 返回非 JSON 两次，出现固定三点自检入口
- [ ] AI 请求超时，允许一次重新分析、重新录音或三点自检
- [ ] 连续发起 10 次后第 11 次显示“今天练得够多了”
- [ ] 同一个 requestId 并发提交时只有一次计费
- [ ] 云文件删除失败时留下 `temp_audio_files` 索引，定时任务后消失

真机测试必须在有权使用的测试 AppID、测试云环境和测试账号中完成；不要在截图、日志或问题单中暴露任何密钥、完整转写或真实工作敏感信息。
